🧠 Quiz sobre Fake News

Teste seus conhecimentos sobre desinformação na internet.

1. Uma publicação afirma: “Após a mudança X, o número de acidentes caiu 30%”. O gráfico apresentado mostra apenas os três meses seguintes à mudança. Qual informação seria mais importante antes de concluir que X provocou a redução?

2. Um perfil publica um trecho verdadeiro de uma entrevista em que uma especialista faz determinada afirmação. Porém, o trecho foi retirado de uma resposta muito maior, na qual ela apresenta uma conclusão diferente. Como o trecho deve ser analisado?

3. Uma pesquisa informa que 70% dos participantes preferem determinado produto. A publicação transforma o resultado em: “70% da população prefere esse produto”. Qual é o principal ponto que precisa ser investigado?

4. Duas matérias apresentam números diferentes sobre o mesmo acontecimento. Depois da comparação, percebe-se que uma considera apenas determinada região, enquanto a outra considera o país inteiro. O que isso demonstra?

5. Um vídeo publicado hoje mostra uma situação que realmente aconteceu, mas a legenda afirma que ela ocorreu durante um evento realizado ontem. A gravação é posteriormente encontrada em uma publicação de três anos atrás. Qual conclusão é mais adequada?

6. Um artigo científico é citado em uma postagem para sustentar uma afirmação. Ao consultar o artigo, você percebe que ele apresenta uma associação entre dois fenômenos, mas não afirma que um deles causou o outro. A postagem, porém, apresenta a relação como causal. Qual análise é mais adequada?

7. Uma matéria apresenta corretamente que determinado indicador aumentou 200%. Em seguida, afirma que isso representa uma “grande maioria” da população. Qual dado adicional seria mais importante para interpretar o primeiro número?

8. Uma página apresenta uma manchete verdadeira, mas utiliza uma fotografia real de outro acontecimento para ilustrar o texto. Qual aspecto deve ser investigado principalmente?

9. Uma pessoa encontra cinco sites afirmando a mesma coisa. Ao investigar, percebe que os cinco reproduzem informações de uma única publicação original, sem apresentar novas evidências. O que essa situação indica?

10. Um especialista é apresentado como fonte de uma informação, mas sua formação é em uma área diferente daquela relacionada ao assunto discutido. Isso significa que:

11. Uma postagem apresenta um dado oficial e, a partir dele, afirma que determinada política “foi responsável” por uma mudança observada no período. Qual etapa adicional seria necessária para sustentar essa relação causal?

12. Uma imagem apresenta pequenos sinais de edição, mas não é possível determinar apenas pela aparência se ela foi manipulada. Qual procedimento oferece uma verificação mais consistente?

13. Uma publicação utiliza uma frase verdadeira para defender uma conclusão que não é sustentada diretamente pelos dados apresentados. Nesse caso, qual cuidado é mais importante?

14. Uma notícia apresenta uma pesquisa com resultado estatisticamente significativo e conclui que o efeito observado é importante para toda a população. Qual distinção deve ser considerada?

15. Você encontra uma publicação com fonte identificada, dados aparentemente reais e uma imagem autêntica. Porém, a conclusão apresentada depende de uma interpretação que não aparece na fonte original. Qual é a avaliação mais adequada?
